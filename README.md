# SaniTap Water Portfolio report

This site is generated weekly by a scheduled Claude task from mWater data (MadAvance hand pumps) and Endur'O records. It is link-only: the pages are not indexed and are not linked from anywhere public. `index.html`, `routes.html` and `itinerary.csv` are overwritten each Monday; `editions/` keeps dated copies of every past edition.

**Before editing anything here, read [CONTRIBUTING.md](CONTRIBUTING.md).** Two rules there are not negotiable and are enforced by `tools/check_consistency.py`: every generated artefact is edited only at its generator, and no script exists at two paths. Both were written after a change was made, committed, and silently undone.
